# Concrete Carbonation Depth Predictor

Standalone Windows desktop app for the closed-form carbonation-depth
equation . Takes the six raw mix-design and exposure
inputs, computes the two engineered predictors, and reports the predicted
carbonation depth, with a warning when an input falls outside the training
envelope.

Download `CarbonationPredictorEq1.exe` and run it. No Python install
required.
